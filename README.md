# Saif Ur Rehman — Full-Stack Developer Portfolio

A responsive, recruiter-focused developer portfolio built with semantic HTML,
modern CSS and JavaScript.

## Highlights

- Full-Stack Developer positioning with React and Django
- Categorized technical skills
- Honest, detailed project case studies
- Responsive and accessible navigation
- SEO and social sharing metadata
- EmailJS contact form with visible status messages
- Reduced-motion accessibility support
- Custom Saif Creative Hub logo and developer brand identity

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy

Upload the contents of this folder to the root of the `SRPortfolio` repository
and enable GitHub Pages for the main branch.
